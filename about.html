About This Project

This website introduces cybersecurity and explains common digital threats, methods of protection, and important security concepts.

The website includes a homepage, two research pages, a key concepts page, a quiz, a references page, and an About page. The quiz uses JavaScript to check answers, calculate scores, and track time.
